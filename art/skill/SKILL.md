# 芯宠：立绘 → 自动动画雪碧图（L2）

## 这个 skill 做什么

一张**透明背景的立绘** → `sprite.png`（512×512，4 列 × 4 行，12 帧）+ 预览图 + GIF + 校验报告。

动作全部由**整体变换**生成，不改画：

| 动作 | 帧号 | 做法 |
|---|---|---|
| 待机 idle | 0–3 | 呼吸缩放 + 轻微上下/摆动 |
| 点击 click | 4–7 | 压扁 → 回弹 → 微晃 → 还原 |
| 拖拽 drag | 8–9 | 左右倾斜 |
| 睡觉 sleep | 12–13 | 下沉 + 缩小 |

空格 10/11/14/15 保持透明，与项目 `src/main/importer.ts` 的校验完全兼容。

## 输入要求

- PNG，**必须透明背景**（没有 alpha 会直接报错，不做抠图）
- 画面里只有**一个**角色，不要带文字、边框、地面阴影
- 边长建议 ≥ 512；太小放大后会糊
- 角色正面或 3/4 侧面效果最好

## 使用步骤

1. 确认输入文件存在，先看一眼是不是透明背景。
2. 运行（Pillow 即可，不需要 Node）：

   ```powershell
   python "<skill目录>\scripts\l2_animate.py" `
     --input "C:\path\to\portrait.png" `
     --out "C:\path\to\out" `
     --name "角色名"
   ```

3. 读 `check.json`：`warnings` 必须为空；有警告就按提示修图或调参数。
4. 把 `preview-sheet.png` 给用户看，确认动作幅度。
5. 交付 `sprite.png`：在芯宠里「托盘 → 导入角色…」选它，或者作为内置素材覆盖 `assets/`。

## 输出

```
out\
├── sprite.png            ← 交付用，512×512
├── preview-sheet.png     ← 12 帧对照
├── preview-idle.gif / click / drag / sleep
└── check.json            ← 尺寸、边距、空格校验
```

## 已知限制（必须提前告诉用户）

- **不能眨眼、闭眼、换表情**：没有眼睛位置信息，睡觉只是下沉+缩小。
- 动作是整体变换，**手/耳朵不会单独动**。
- 想要挥手、摸头、生气这类动作，得走 L3（完整雪碧图）或内置的 36 帧模板。

## 与内置素材的区别

| | 这个 skill（L2） | 内置三套（L3） |
|---|---|---|
| 网格 | 4×4 / 12 帧 | 4×9 / 36 帧 |
| 来源 | 一张立绘自动生成 | 矢量模板逐帧绘制 |
| 导入器 | ✅ 直接支持 | ❌ 导入器只认 4×4 |

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 报“没有透明背景” | 白底/不透明 | 先抠图再跑 |
| 边距警告 | 原图带阴影/留白太少 | 裁掉阴影，让角色占满画面 |
| 动作太轻 | 原图本身是全身远景 | 裁到角色主体再跑 |
| 动作幅度想更大 | 默认参数保守 | 改脚本里的 `FRAMES` 位移/缩放值 |
