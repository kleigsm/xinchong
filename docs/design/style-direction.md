# UI 风格升级：从“通用卡片”到有辨识度

> 问题：现在的界面圆角几乎一样、全是白卡 + 软阴影 + 同一个珊瑚色，
> 看起来像通用模板。下面给三个方向，选一个再细化。
>
> 2026-11-21 追加：如果觉得贴纸版仍然是“卡片换皮”，
> 见更彻底的结构方案 [style-alternatives.md](style-alternatives.md)：
> 栖息地 / 编辑图鉴 / 街机选人 / 复古 OS。

---

## 一、现状为什么“大众化”

| 表现 | 问题 |
|---|---|
| 圆角 14/16/18/20/22/24/26 混用但视觉接近 | 没有节奏，全是“圆” |
| 卡片全白、阴影全是柔和模糊 | 没有硬边/层次，像默认组件库 |
| 主色只有珊瑚一个 | 缺少第二、第三色，注意力没有落点 |
| 字号 12–25，正文 400 | 层级靠大小，不靠字重/字色 |
| 没有纹理、贴纸、旋转、描边 | 缺少“手作感/个性” |
| 侧栏、标题栏、卡片同一套圆角 | 没有“窗口/纸张/物件”的区别 |

## 二、参考

### 1. Playful Cream Sticker（贴纸手账）

- 奶油纸底 `#FFFCF5`，从不用纯白当页面底
- 每张卡 **2px 暖墨描边**，阴影是 **4px 4px 0** 的硬偏移，不是模糊阴影
- 卡片/头像/贴纸允许 **1–2° 轻微旋转**，hover 回正
- 标题用粗体（700–900），正文也偏粗，几乎没有 400
- 黄色贴纸角标、点阵/纸纹、混合圆角（一个角更大）

参考：https://sleek.design/design-md/playful-cream-sticker-3fZzrmE8waL

### 2. Candy OS（糖果桌面）

- 4px 黑色描边，**双层硬阴影**（粉 + 墨）
- 点阵薄荷底、手绘图标、窗口化面板
- 弹簧动效：back.out / elastic，拒绝淡入淡出
- 更像“玩具操作系统”，个性最强，但也最容易幼态

参考：https://sibhimanyu.github.io/rasanai/systems/candy-os.md

### 3. 展柜 / 工作台

- 宠物站在“架子”上，形象卡像相框/CD 盒
- 强空间纵深、聚光灯、材质，少用网格
- 更像 Wallpaper Engine 的“库”，但更温暖

参考结构：Wallpaper Engine 的左侧库 + 大预览 + 详情，不照搬皮肤。

## 三、三个方向对比

| 方向 | 辨识度 | 与桌宠气质 | 实现成本 | 风险 | 结论 |
|---|---|---|---|---|---|
| **A 贴纸手账** | 高 | 很搭 | 中 | 旋转/纹理过多会乱 | **推荐** |
| B 糖果桌面 | 最高 | 偏幼态 | 中高 | 4px 黑边+双层阴影容易太重 | 可做局部 |
| C 展柜/工作台 | 高 | 稳、偏高级 | 高 | 需要重做布局/素材 | 二期备选 |

**推荐 A + 少量 B 的硬边**：

- 纸张/贴纸/硬偏移阴影来自 A
- 4px 描边、双层阴影只用在“重点卡/弹窗”，不全站铺开
- 保留 6 项导航和双主题，不动信息架构

## 四、具体改什么

### Token

| 项 | 现在 | 贴纸手账 |
|---|---|---|
| 页面底 | `#F7F2EA` | `#FBF3E4` 奶油纸 + 点阵纹理 |
| 卡片 | `#FFFFFF` | `#FFFDF7`，2px 墨线 |
| 描边 | 无/1px 浅线 | `2px solid #2E2521` |
| 阴影 | 柔和大模糊 | `4px 4px 0 #E7CDB4` 硬偏移 |
| 圆角 | 14–26 混用 | 8 / 12 / 16 / 22 四档 |
| 主色 | 珊瑚 | 珊瑚 + 柠檬黄 + 天空蓝（少量） |
| 标题 | 25px/700 | 26px/800，字距 -0.5 |
| 正文 | 12px/400 | 12–13px/500–600 |
| 图标 | 1.8px 线性 | 2px 粗线 + 色块底 |

### 组件

- **侧栏**：像一张贴在桌上的纸卡，2px 墨边 + 硬阴影
- **导航选中**：不是白卡，而是“贴纸标签”——浅色底 + 墨边 + 2px 硬阴影 + 1° 旋转
- **Hero**：厚边框 + 大硬阴影，像一张相纸
- **形象卡**：2px 墨边，使用中卡片换成主色硬阴影；第 2/3 张轻微旋转
- **分区标题**：黄色贴纸条，不是普通 H3
- **按钮**：主按钮带墨边 + 硬阴影；次按钮纸白底
- **大厅详情**：像一张“收藏卡”，作者/许可用等宽小字
- **右键面板**：毛玻璃保留，但加 2px 墨边和硬阴影，避免和系统菜单混淆

### 动效

- 悬浮 120ms，旋转回正
- 面板入场 160ms，scale 0.98→1
- 不做大面积模糊/发光动画
- 尊重 `prefers-reduced-motion`

## 五、双主题

### 浅色：奶油手账

- 纸底 `#FBF3E4`，点阵 `#D9C3AA` 3–5% 透明
- 墨线 `#2E2521`，硬阴影 `#E7CDB4`
- 珊瑚主色，柠檬黄只做贴纸/强调

### 深色：夜光手账

- 纸底 `#17181C`，点阵 `#3A3D45`
- 墨线 `#F3EEE8`，硬阴影 `#08090B`
- 薄荷主色，硬阴影可换成主色（重点卡）
- 不做“整页反色”，保留纸张质感

两套都只切 CSS 变量。

## 七、需要拍板

1. 选 **A 贴纸手账**、**B 糖果桌面**，还是 **C 展柜**？
2. 旋转/点阵纹理的剂量：**克制**（推荐，约 20% 元素）还是 **明显**？
3. 是否允许在“重点卡/弹窗”用 4px 黑边 + 双层硬阴影（Candy 元素）？
