# 控制中心设计规范（浅色 / 深色）

> 对应 [navigation-redesign.md](navigation-redesign.md) 的 B 方案。
> 主题不再是“二选一”，而是**同一套结构的两套 token**。
>
> **2026-11-21 布局改为沉浸式游戏库**：窗口结构、舞台、shelf、玻璃信息卡
> 以 [immersive-layout.md](immersive-layout.md) 为准；
> 本文的颜色/字体/组件基础仍可复用，旧“左侧栏 + 卡片”布局作废。

---

## 1. 主题模型

```ts
type ThemeMode = "system" | "light" | "dark";
```

- 默认 `system`：跟随 Windows 应用主题
- 设置 → 外观 → 主题：跟随系统 / 浅色 / 深色
- 只切 CSS 变量，不换 DOM、不换图片资源
- 桌宠透明窗不受影响；只作用于控制中心 / 设置 / 右键面板

## 3. 组件

### 侧栏

- 品牌区：36px logo + 名称 + 英文小字
- 6 个导航项：图标 18 + 文字 13
- 当前项：白卡 + 阴影 + 主色图标
- 底部：推荐卡 + 用户/版本

### 导航（6 项）

| 导航 | 图标 | 包含 |
|---|---|---|
| 我的形象 | 爪印 | 当前形象、全部角色、导入 |
| 外观大厅 | 星芒 | 策展目录、详情、下载 |
| 声音台词 | 音量 | 音效主题、音量、静音、试听 |
| 行为 | 滑杆 | 双击/长按、待机睡觉、置顶、速度、透明度 |
| 系统 | 显示器 | 开机自启、性能、数据目录、聊天 Key |
| 关于 | 信息 | 版本、许可、致谢 |

### 我的形象

- Hero：左侧文案 + 右侧宠物大图
- 状态 chips：使用中 / L2·L3 / 内置
- 动作按钮：招手、摸头、睡觉、隐藏
- 形象卡：缩略图 + 名称 + 性格/来源；使用中珊瑚描边
- 第 4 张固定为「导入新形象」虚线卡

### 外观大厅

- Featured banner：本周推荐 + CTA
- 分类 chips：全部/猫/狗/鸟/幻想/节日
- 3 列卡片 + 右侧详情 226px
- 详情：作者、许可、大小、版本、更新时间
- 主按钮「下载并使用」，次按钮「预览动画」

### 右键面板

- 306px 宽；透明窗 + 毛玻璃
- 头部：头像 + 名字 + 状态
- 4 动作块 + 性格分段 + 音量 + 静音/勿扰
- 底部：打开控制中心 / 退出
- 状态与主设置双向同步

## 4. 状态

| 状态 | 表现 |
|---|---|
| hover | 背景 +4% 亮/暗，不改变布局 |
| active | 主色描边或主色文字 |
| focus | 2px 主色外环，键盘可见 |
| disabled | 40% 透明，不响应 |
| loading | 骨架块，不转圈 |

---

## 5. 可访问性

- 正文对比度 ≥ 4.5:1；大标题 ≥ 3:1
- 所有可点击元素有 `:focus-visible`
- 支持 Tab / Enter / Esc
- 图标按钮带 `aria-label`
- 不只靠颜色表达状态（配文字/描边）

---

## 6. 适配

- 1040×700 基准；900×600 时侧栏可收成 64px 图标栏
- 125% / 150% 用 DIP，不写死物理像素
- 多屏：窗口位置夹在工作区

---

## 7. 实现方式

- 新建 `src/renderer/control-center/`（或复用 settings 壳）
- CSS 变量放 `theme.css`，`html[data-theme="dark"]` 覆盖
- 设置项 `theme` 持久化；`nativeTheme.shouldUseDarkColors` 监听系统切换
- 不引入 UI 框架；沿用现有原生 DOM + CSS
- 先做 P1：壳 + 6 导航 + 我的形象 + 双主题
