# 导航与右键快捷面板：改造方案

> 背景：答辩后导师反馈“导航过于基础、人机化”。
> 目标：参考 Wallpaper Engine 的导航语言，让用户**直接管理形象**、**进入外观大厅**，
> 右键快捷设置也要有产品感。

**已定（2026-11-21）：**

- 采用 **B 方案**（控制中心 + 快捷面板）
- 视觉 **浅色 + 深色都做**，同一套结构两套 token
- 导航合并为 **6 项**
- 右键面板替换原生菜单，作为**独立 issue** 提交

> **2026-11-21 布局定稿：** 采用 **沉浸式游戏库**（Wallpaper Engine / Steam Big Art / PS5 方向）。
> 本文第 4 节的“左侧栏 + 卡片网格”已作废，
> 以 [immersive-layout.md](immersive-layout.md) 和 `mockups/immersive.html` 为准。

## 二、产品闸（先划边界）

**做：**

- 让“当前宠物”成为视觉主角
- 形象管理：预览、切换、导入、删除，2 次点击内完成
- 外观大厅：浏览、看详情、下载/使用外观
- 右键快捷面板：高频操作一屏完成
- 视觉与桌宠一致：暖色、圆角、轻量动效

**不做：**

- 不做 Wallpaper Engine 的创意工坊/账号/评论/订阅
- 不做用户上传、审核后台、支付
- 不做聊天/养成/主动打扰
- 不把用户图片上传云端

**大厅 v1 只做“策展”**：官方/内置外观的静态目录，不做 UGC 上传。

| 方案 | 内容 | 成本 | 风险 | 结论 |
|---|---|---|---|---|

3. **P3 UGC/工坊**：暂不排期

## 五、右键快捷面板（P1）

### 为什么不用原生菜单

原生 `Menu` 在 Windows 上无法改圆角、间距、图标、动效，也无法放开关/滑块。
要产品感，必须换成 HTML 面板。

### 形态

- 独立透明无边框窗口：320×420
- 圆角 20、毛玻璃/浅色卡片、轻微缩放入场
- 出现在鼠标右上方；超出屏幕自动翻转
- 点击外部、Esc、失焦自动关闭
- 不占任务栏，不抢焦点太久

### 内容（高频一屏）

```
┌────────────────────────────┐
│  [头像] 小芯  害羞 · 使用中 │
│                            │
│  [招手] [摸头] [睡觉] [隐藏]│
│                            │
│  性格  [害羞][开朗][傲娇]   │
│  音量  ────────●────  70%   │
│  [ ] 静音   [ ] 勿扰        │
│                            │
│  [打开控制中心]      [退出] │
└────────────────────────────┘
```

- 「我的角色」不再放二级菜单，改为「打开控制中心 → 我的形象」
- 导入/删除这类低频操作只放控制中心
- 面板内按钮复用设置页的 CSS 变量和控件

### B 线实现要点

- 主进程监听右键 → `openQuickPanel({x,y})`
- `BrowserWindow`: `transparent`, `frame:false`, `alwaysOnTop`, `skipTaskbar`, `resizable:false`
- `blur` 关闭；`setIgnoreMouseEvents` 只在面板外区域按需
- 多屏/DPI：用 `screen.getDisplayNearestPoint` 限制边界
- 关闭时销毁或隐藏复用（建议隐藏复用，二次打开 <100ms）

## 六、外观大厅（P2）

### v1 范围

- 只展示**策展外观**（官方/内置/合作），不做用户上传
- 静态 `catalog.json` + 预览图 + zip 包
- 详情：大图、作者、许可、大小、版本、标签
- 「下载并使用」→ 下载 zip → 校验 → 解压到用户目录 → 切为当前形象
- 离线：已下载的显示在「我的形象」，大厅可缓存列表

### 数据格式

```json
{
  "version": 1,
  "items": [
    {
      "id": "sakura-cat",
      "name": "樱花猫",
      "author": "芯宠官方",
      "license": "CC0",
      "tags": ["猫", "粉色"],
      "preview": "https://.../sakura-cat/preview.png",
      "download": "https://.../sakura-cat.zip",
      "sha256": "...",
      "size": 2400000,
      "version": 1
    }
  ]
}
```

### 安全与版权

- 只允许 zip 内 `pack.json` + 图片/音频，拒绝可执行文件
- 下载后校验 sha256，解压路径防穿越
- 每项必须带 license/author，非商用素材不进大厅
- 不上传用户图片，不收集账号

### 托管

- 先放 GitHub Releases / 静态对象存储
- 无后端、无账号；后续要 UGC 再评估

## 七、双主题（浅色 + 深色）

同一套 6 项导航和组件，只切 CSS token；不是两套页面。

### 浅色 · 暖奶油

- 底 `#F7F2EA`，卡片 `#FFFFFF`，主色珊瑚 `#F0603C`
- 大圆角 20–26，柔和阴影，深棕文字 `#2E2521`
- 和现有三套角色、petpet 手掌一致

### 深色 · 工作室

- 底 `#141519`，卡片 `#1E2026`，主色青 `#5EE0D0`
- 大图对比强，更接近 Wallpaper Engine
- 预览舞台局部发光，不整页反色

### 规则

- 默认 `system`，跟随 Windows 应用主题
- 设置 → 外观 → 主题：跟随系统 / 浅色 / 深色
- 只切变量，不换 DOM、不换图片
- 桌宠透明窗不受影响

完整 token 与组件见 [design-system.md](design-system.md)。
