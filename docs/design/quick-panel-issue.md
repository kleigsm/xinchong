# 右键快捷面板 · Issue 文案

**标题**

```
[建议] 右键菜单改为 HTML 快捷面板
```

**正文**

```markdown
## 背景

导航改造 P1 的一部分。当前桌宠右键是 Electron 原生 Menu：
12 个一级项 + 4 个二级菜单，无法定制视觉，高频操作（招手/摸头/静音）被埋在二级，
和新的控制中心风格脱节。

## 建议

- 桌宠右键改为独立透明 HTML 面板（306px 宽）
- 面板内：招手 / 摸头 / 睡觉 / 隐藏 / 性格 / 音量 / 静音 / 勿扰
- 托盘菜单保留原生（系统托盘更适合原生）
- 点击外部 / Esc / 失焦关闭；多屏自动翻转
- 异常时回落原生菜单
- 低频操作（导入/删除/系统设置）只进控制中心

## 不做什么

- 不改托盘菜单
- 不做环形菜单
- 不做多级子菜单
- 不引入新 UI 框架

## 验收

- [ ] 右键 100ms 内出现，不超出屏幕
- [ ] 点击外部 / Esc / 失焦关闭，无残留透明窗
- [ ] 4 个动作、性格、音量、静音、勿扰全部生效
- [ ] 125% / 150% / 多屏不错位
- [ ] 键盘可操作（Tab / Enter / Esc）
- [ ] 异常时能回落原生菜单
- [ ] 空闲 CPU 与旧版持平

## 设计稿

- `docs/design/mockups/shots/quick-panel.png`（浅色）
- `docs/design/mockups/shots/quick-panel-dark.png`（深色）
- 方案与实现建议：`docs/design/quick-panel-request.md`

## 估时

B 线 3–4 天。

## 备注

依赖控制中心的 CSS token 与 preload API；建议分支 `feat/quick-panel`。
```
