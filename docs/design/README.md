## 怎么打开原型

**方式 A：直接双击**

`docs/design/prototype/index.html` 用 Chrome / Edge 打开即可。角色贴图用的是仓库里的
`src/renderer/assets/pet-shy.png`，所以**要在仓库目录内打开**（整个 `docs/` 别单独拷走）。

**方式 B：起个本地服务**（推荐，避免浏览器对 file:// 的限制）

```bash
# 在仓库根目录（E:\wt-work）
npx serve .
# 然后打开 http://localhost:3000/docs/design/prototype/index.html
```

## 原型里能试什么

左侧面板是场景入口，右侧是模拟桌面：

| 场景 | 操作 |
|---|---|
| ① 长按浮球 | **按住桌宠 2 秒**：1.2 s 先摸头，2 s 弹出 4 个球 |
| ② 右键菜单对比 | 面板切换「现在 / 改版」，再右键桌宠 |
| ③ 贴边收纳 | 点一下，桌宠收到右边只露一半，鼠标移上去滑出 |
| ④ 说句话 | 浮球第一个 / 面板按钮，输入条可打字、回车有回显 |
| ⑤ 省电模式 | 动画停住（对应"静止模式"提案） |
| 标注 | 打开后显示 320×340 窗口、角色、输入条、命中圆 |

## 关于交互的几条约定

1. **同一时刻只有一个面板**：开浮球会关输入条，反之亦然。
2. **浮球只由长按触发**，不会自己冒出来（守住"不主动打扰"）。
3. **浮球区域必须计入命中区域**，否则会和 11-08 的输入条 bug 一样点不着。
4. **动画只用 transform / opacity**，禁止 `filter`（透明窗口上实测 42.7% CPU）。
