## #1 右键菜单点空白处不关闭

- **现象**：右键桌宠弹出菜单后，左键点击菜单外的空白区域，菜单仍然保持显示。
- **复现步骤**：
  1. 右键点击桌宠，弹出右键菜单；
  2. 左键点击桌面或其他窗口的空白处；
  3. 观察菜单是否消失。
- **期望**：点击菜单外任意位置后，菜单应立即关闭。
- **严重度**：P2
- **状态**：待修复

---

## #2 长时间放置后左键点击 / 拖拽失效

- **现象**：桌宠静置较长时间后，左键点击无反应，也无法拖动桌宠；右键菜单仍能正常弹出。
- **复现步骤**：
  1. 启动芯宠，将桌宠静置较长时间（进入睡觉 / 久未互动状态）；
  2. 左键点击桌宠，观察是否有反馈；
  3. 尝试拖动桌宠，观察是否跟手；
  4. 右键点击桌宠，对比是否正常。
- **期望**：无论放置多久，左键点击和拖动都应正常响应。
- **严重度**：P1
- **状态**：待修复

---

## #3 初始音量显示 0% 但仍有声音

- **现象**：首次打开芯宠时，设置里音量显示 0%，但点击桌宠仍有声音；把音量调高后再调回 0% 才真正静音。
- **复现步骤**：
  1. 首次启动芯宠（或初始化设置后）；
  2. 打开设置面板查看音量，显示 0%；
  3. 点击桌宠，能听到声音；
  4. 将音量调大，再调回 0%，此时点击桌宠才静音。
- **期望**：音量显示 0% 时即为静音，显示与实际一致。
- **严重度**：P1
- **状态**：待修复
