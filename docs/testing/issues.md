# 问题池

> 测试期间发现的所有问题都记在这里。**不要直接改代码，先记一条。**

---

## 怎么用（三步）

1. **发现问题** → 往下翻，找到最后一个编号，+1（如 `BUG-012`）
2. **在文件末尾追加一段**（复制下面的模板）
3. **别改别人写的行**——只追加，或改自己那条的「状态」

```markdown
### BUG-012 一句话说清现象

- **发现**：2026-11-09 / 谁发现的
- **环境**：Windows 11 / 125% 缩放 / `pnpm dev` 或 打包 exe
- **现象**：看到了什么（写具体，别写"不好用"）
- **复现**：
  1. 打开设置
  2. 点「角色」
  3. 看到白屏
- **期望**：应该看到什么
- **严重度**：P1
- **状态**：⬜ 待修
- **备注**：（截图路径、日志片段、其他线索）
```

---

## 严重度怎么定

| 级别 | 含义 | 例子 |
|---|---|---|
| **P0** | 装不上 / 打不开 / 崩溃 / 数据丢失 | 双击没反应、设置全白 |
| **P1** | 功能不可用，但有绕路 | 聊天发不出去、拖拽丢宠物 |
| **P2** | 能用但体验差 | 台词重复、动画太慢、字太小 |
| **P3** | 建议 / 锦上添花 | 想加个快捷键、颜色不好看 |

## 状态怎么标

| 状态 | 含义 |
|---|---|
| ⬜ 待修 | 还没人动 |
| 🔄 修中 | 有人在做（备注里写 PR 号） |
| ✅ 已修 | 合并进 main 了（备注里写 PR 号） |
| 🙅 不修 | 有明确理由（备注里写为什么） |
| ❓ 待确认 | 现象不清楚，需要复现 |

### BUG-001 设置面板在 `pnpm dev` 下是白板

- **发现**：2026-11-09 / 高晟铭
- **环境**：Windows 11 / `pnpm dev`
- **现象**：桌宠正常，右键「设置…」打开是一片白色，什么都没有
- **复现**：
  1. `pnpm dev`
  2. 右键桌宠 → 设置…
- **期望**：出现设置面板
- **严重度**：P0
- **状态**：✅ 已修
- **备注**：根因是设置窗口写死 `loadFile(out/renderer/settings/index.html)`，
  但 dev 模式下该文件不存在。已补 `ELECTRON_RENDERER_URL` 分流。PR #49。

### BUG-002 聊天输入框点不进去

- **发现**：2026-11-09 / 高晟铭
- **环境**：v0.1.0 开发版
- **现象**：右键「说句话…」输入条能弹出，但鼠标点上去没反应，打不了字
- **复现**：
  1. 右键 → 说句话…
  2. 点输入框
- **期望**：光标进入输入框
- **严重度**：P1
- **状态**：✅ 已修
- **备注**：输入条画在角色上方，不在命中圆里，窗口处于穿透态。PR #45，v0.1.1 已包含。

### BUG-003 聊天第二次打开输入框打不了字
