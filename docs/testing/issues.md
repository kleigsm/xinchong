## 怎么用（三步）

1. **发现问题** → 往下翻，找到最后一个编号，+1（如 `BUG-012`）
2. **在文件末尾追加一段**（复制下面的模板）
3. **别改别人写的行**——只追加，或改自己那条的「状态」

```markdown
### BUG-0XX 一句话说清现象

- **发现**：2026-11-09 / 谁发现的
- **环境**：Windows 11 / 125% 缩放 / `pnpm dev` 或 打包 exe
- **现象**：看到了什么（写具体，别写"不好用"）
- **复现**：
  1. 打开设置
  2. 点「角色」
  3. 看到白屏
- **期望**：应该看到什么
- **严重度**：P1
- **状态**：⬜ 待修
- **备注**：（截图路径、日志片段、其他线索）
```

---

## 严重度怎么定

| 级别 | 含义 | 例子 |
|---|---|---|
| **P0** | 装不上 / 打不开 / 崩溃 / 数据丢失 | 双击没反应、设置全白 |
| **P1** | 功能不可用，但有绕路 | 聊天发不出去、拖拽丢宠物 |
| **P2** | 能用但体验差 | 台词重复、动画太慢、字太小 |
| **P3** | 建议 / 锦上添花 | 想加个快捷键、颜色不好看 |

## 状态怎么标

| 状态 | 含义 |
|---|---|
| ⬜ 待修 | 还没人动 |
| 🔄 修中 | 有人在做（备注里写 PR 号） |
| ✅ 已修 | 合并进 main 了（备注里写 PR 号） |
| 🙅 不修 | 有明确理由（备注里写为什么） |
| ❓ 待确认 | 现象不清楚，需要复现 |

### BUG-014 长时间放置后左键点击 / 拖拽失效

- **发现**：2026-11-09 / 朱哲弘
- **环境**：v0.1.1 打包版
- **现象**：静置很久（睡着 / 久未互动）后，左键点击无反应、拖不动，**但右键菜单正常**
- **复现**：
  1. 启动后放着不管，等它睡着
  2. 左键点它 → 无反应
  3. 试着拖 → 不跟手
  4. 右键 → 菜单正常
- **期望**：随时都能点击和拖动
- **严重度**：P1
- **状态**：❓ 待复测
- **备注**：**PR #55 疑似已修**（`playOneShot()` + 700ms 兜底），需要在新版复测确认后再标已修。
- **备注**：**根因很可能是帧缺失导致状态机卡死**——
  v0.1.1 里 4/5 行素材没有 `stretch` 帧，睡着后点一下进入 `stretch` 状态，
  `view.play()` 找不到动画就直接返回，**永远不会回到 idle** → 后续点击全被吞。
  右键是主进程菜单，不经过状态机，所以正常。
  PR #55 的 `playOneShot()` + 700ms 兜底已修掉这个。**请在新版复测。**
