## 七、发布被什么卡住

**上行带宽只有 ~50 KB/s**（实测直连 GitHub）。

| 路径 | 结果 |
|---|---|
| 直连上传 | 51.7 KB/s → 135MB 要约 44 分钟，且中途断过一次 |
| 走 Clash 代理 | 16.5 KB/s（更慢） |

**建议解法**：GitHub Actions 云端构建。只推几 MB 源码，135MB 的包在 GitHub 机房内部生成，不经过本地上行。

这个还没配，是发布环节的主要阻塞。

## 十、环境与约定（新人必看）

- **项目路径必须是短英文**（`E:\xinchong` / `D:\xinchong`），中文路径会让 Electron **静默崩溃**
- `main` 有分支保护，**必须走 PR**；直接推会被拒绝
- 一个任务 = 一个分支 = 一个 PR；改代码的 PR 要同时更新本文件和一篇日志
- 先读 [`AGENTS.md`](../AGENTS.md) → 本文件 → [`BACKLOG.md`](BACKLOG.md) → 最近日志 → [`DECISIONS.md`](DECISIONS.md)
