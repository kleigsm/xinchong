## 四、必须覆盖的场景（至少 25 条）

### A. 启动与退出（7 条）

- **三种启动方式各跑一遍**：`pnpm dev` / `pnpm start` / 打包 exe
  （行为不同！`pnpm dev` 的渲染层走 Vite、不产出 `out/renderer`，
  设置窗口曾因此白板，见 BUG-001）
- 冷启动 / 热启动（第二次打开）
- 托盘有图标、右键能出菜单
- 退出后任务管理器无残留进程
- 开机自启开启后重启电脑

### B. 窗口行为（6 条）

- 点击穿透：鼠标在透明区域时点下面的窗口能点中
- 鼠标移到宠物身上时能点中它
- 拖拽：拖到屏幕四边、拖到任务栏
- **多显示器**：拖到第二块屏
- **150% / 200% 缩放**下窗口是否错位
- 分辨率切换后位置是否还在可见区域

### C. 交互（6 条）

- 单击 / 双击 / 长按 1.2 秒 / 1.2 秒内三连点
- 快速连点 10 次不崩
- 睡着后点一下 → 伸懒腰
- 拖拽中按 Esc / Alt+Tab
- 右键菜单各项都能点

### D. 角色与素材（5 条）

- 导入单张立绘（正常图）
- 导入雪碧图（4 行 / 5 行 / 9 行）
- **导入坏图**：白底图、尺寸不对、非 PNG、超大图 —— 每种看错误提示是否说人话
- 切换性格（三套来回切 5 次）
- 删除当前角色后是否退回内置

### E. 设置（4 条）

- 改音量、静音、勿扰是否立即生效
- 改「入睡时间」为不睡 / 5 分钟
- 关手势开关后手势是否失效
- 改成 125% 缩放后设置窗口是否错乱

### F. 聊天（4 条）

- 没配 Key 时点「说句话…」→ 应该弹提示
- Key 填错 → 应该提示无效并回落
- 断网时发消息 → 应该回落内置台词
- **连续对话 3 轮**（验证输入框每次都能打字）
