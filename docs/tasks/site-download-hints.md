## 一、要做什么

v0.1.0 已经发布，官网下载按钮可用了。但真实用户会遇到三个问题，页面上**一个字都没提**：

| 问题 | 用户会遇到什么 |
|---|---|
| GitHub CDN 在部分国内网络下直连不通 | 点下载**没反应或很慢**（实测直连 19 秒后失败，走代理 38 秒下完） |
| 未做代码签名 | Windows 弹「未知发布者」，很多人会直接关掉 |
| 不知道能干什么 | 下载完不知道能双击、长按、右键聊天 |

---

## 二、要改的三处

### 1. 下载区加一句提示（最重要）

在下载按钮下方加提示，说明两件事：

- 下载慢或失败是 **GitHub 的 CDN 在部分网络下不稳定**，可以开代理，或联系作者要网盘镜像
- 首次运行 Windows 可能提示"未知发布者"，点"更多信息 → 仍要运行"

**语气要克制**，不要写成免责声明，写成"小提示"。

### 2. 加一个「已知问题」区块

诚实列出：

- 台词量偏少（点击约 5 条），后续版本会补
- 音效为程序合成，暂无真实素材
- 未做代码签名
- 未做「仅窗口内模式」（双通道已搁置）

> 诚实反而加分：答辩时被问到"还差什么"，你有现成答案。

### 3. 加一个「怎么玩」入口

把桌面端的交互说明搬一部分到官网，让用户下载前就知道能玩什么：

- 单击 / 双击 / 长按 / 连点三下 / 拖拽
- 右键菜单能干什么

可以做一个简单的四格图文，不用做交互。
