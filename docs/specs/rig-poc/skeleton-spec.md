# 骨骼模板规格

> 坐标统一：512×512 画布，原点左上，x 向右、y 向下；骨骼位置为**画布绝对坐标**。
> POC 只实现 `quadruped/dog`，其余三套为后续预留。

---

## 1. 通用规则

- 每个部件一张 **透明 PNG**，画布尺寸与模板一致
- 骨骼只做**旋转 + 平移**，不做非均匀缩放（身体允许整体 scale）
- 图层 pivot 必须落在关节上：头在脖子、耳朵在耳根、腿在肩/胯、尾巴在尾根
- 图层 z 值越大越靠前；身体在腿和尾巴之上、头之下
- 命名：小写 + 连字符，如 `front-leg-l.png`

## 6. 设计约束

- 所有部件必须在 512×512 内，四周至少留 8px
- 相邻部件重叠 4–8px，旋转时不露缝
- 腿/尾巴这类细长件，pivot 放在根部，末端可自由摆
- 眼睛、嘴、腮红可以合进头层，POC 不做眨眼
- 不允许用阴影/发光做半透明大图层，合成成本高
