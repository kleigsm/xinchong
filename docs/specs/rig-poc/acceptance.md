## 八、Go / No-Go

**必须全过：**

- LOAD-01/02/03、VIS-01、ACT-01~08、INT-01~07、PERF-01/02/05
- 没有 P0 级崩溃或白屏

**允许 ≤1 个 P1 遗留**（写清计划），例如：

- DPR 缩放边缘 1px 误差
- 某个动作弹簧略硬

**直接 No-Go：**

- idle CPU >8%
- 8 个动作里有 2 个以上明显错位
- 需要 GPU 或安装 >500MB 才能跑
- 破坏 L2/L3 现有角色
