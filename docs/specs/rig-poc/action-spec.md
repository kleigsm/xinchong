# 动作规格（POC 8 个动作）

> 时间单位：秒；角度单位：度；位移单位：px（512 画布）。
> 所有动作由运行时按本规格**程序化生成**，不需要逐帧图片。

---

## 1. 通用参数

| 项 | 值 |
|---|---|
| 画布 | 512×512 |
| 目标帧率 | idle 30fps；交互动作 30–60fps |
| 最大 dt | 1/30s（掉帧时钳制，避免跳变） |
| 缓动 | 回弹 `cubic-bezier(0.34, 1.56, 0.64, 1)`；其余 ease-out |
| 弹簧 | 耳朵 stiffness 180 / damping 14 / maxAngle 25°；尾巴 120 / 10 / 35°；腿 160 / 12 / 20° |

---

## 2. idle（待机，循环）

- 时长：2.4s
- 身体：`scaleY 1.00 → 1.02 → 1.00`，`y +0 → -3 → 0`
- 头：`rotate -1° → +1° → -1°`
- 耳朵/尾巴：交给弹簧，跟随身体
- 验收：循环处不能有跳帧；呼吸幅度肉眼可见但不夸张

## 3. click（被点，单次）

- 时长：0.35s
- 0.00：`scale(1,1)`
- 0.08：`scale(1.08, 0.92)`，`y +4`
- 0.18：`scale(0.96, 1.05)`，`y -4`
- 0.28：`scale(1.02, 0.98)`
- 0.35：`scale(1,1)`
- 验收：有“压扁→弹回”，不能只放大

## 4. drag（被拖拽，循环）

- 时长：1.2s
- 身体：`rotate -6° → +6° → -6°`
- 前腿：`rotate ±8°`，后腿 `∓6°`（像悬空晃）
- 尾巴：`rotate -15° → +15°`
- 验收：拖拽中动作连续，松手能回 idle

## 5. sleep（睡觉，循环）

- 时长：2.0s
- 身体：`y +6`，`scale 0.96`
- 头：`rotate 8°`，`y +6`
- 耳朵：下垂 15°
- 尾巴：贴地，`rotate 10°`
- 可选：Zzz 由特效层负责，不在骨骼里
- 验收：看起来是“趴下睡”，不是整体缩小

## 6. wave（招手，单次）

- 时长：0.6s
- 四足没有手：用**右前腿**抬起
- 0.00：0°
- 0.15：`rotate -80°`
- 0.30：`rotate -50°`
- 0.45：`rotate -80°`
- 0.60：回 0°
- 验收：抬腿不穿身体，能看出“挥两下”

## 7. stretch（伸懒腰，单次）

- 时长：0.8s
- 身体：`scaleY 1.08`，`y -6`
- 头：`rotate -6°`（抬头）
- 前腿：`rotate -20°`（往前伸）
- 后腿：`rotate +8°`
- 尾巴：上翘 20°
- 验收：身体明显拉长，再回弹

## 8. pat（摸头，单次）

- 时长：0.6s
- 头：`scale 0.96`，`y +4`
- 耳朵：下垂 20°
- 身体：`scaleY 0.97`
- 尾巴：轻摆 ±8°
- 验收：头被“按下去”，不是整体缩放

## 9. angry（生气，单次）

- 时长：0.5s
- 身体：`x ±4` 快速左右抖
- 头：`rotate ±3°`
- 尾巴：竖直、`rotate ±10°`
- 耳朵：后压 10°
- 验收：气但不凶，不能出现暴走式抖动

---

## 10. 动作切换规则

| 当前 | 事件 | 目标 |
|---|---|---|
| idle | 单击 | click → idle |
| idle | 双击 | wave → idle |
| idle | 长按 1.2s | pat → idle |
| idle | 连点 3 下 | angry → idle |
| idle | 30s 无互动 | sleep |
| sleep | 单击 | stretch → idle |
| 任意 | 拖拽 | drag |
| drag | 松手 | idle |

- 一次性动作播完必须回 idle
- 新动作可打断旧动作，但不能叠加两套骨骼动画
