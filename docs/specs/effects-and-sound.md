# 通用动作小特效 + 音效发展方案

> 目标：让 8 个动作在“动作本身”之外多一层轻反馈，但**不增加卡顿**。
> 现有约束：透明窗口、点击穿透、空闲 CPU 红线 5%。

---

## 一、通用动作小特效

### 1. 原则

- 只在**状态切换**时播一次，不常驻
- 只用 CSS `transform` / `opacity`，不用 `filter`、Canvas、逐帧重绘
- 单一特效层，同一时间只允许一个特效，避免叠加
- 特效不挡点击：`pointer-events: none`
- 尊重「动画速度」设置：0.5× 时特效时长 ×2，2× 时 ×0.5

### 2. 实现方式

在 `index.html` 加一个固定在宠物上方的图层：

```html
<div id="fx-layer" aria-hidden="true"></div>
```

- 用 **内联 SVG 或小 PNG** 做 4 种基础粒子：`sparkle`、`heart`、`anger`、`zzz`
- 每个特效 = 1 个 DOM 节点 + 一组 CSS keyframes，播完 `animationend` 移除
- 位置相对 `#pet` 的包围盒计算，不写死在窗口坐标里

### 3. 各动作的特效建议

| 动作 | 特效 | 时长 | 优先级 |
|---|---|---|---|
| click | 2–3 颗小星星从被点位置散开 | 350ms | P0 |
| pat | 头顶飘 2 颗爱心 + 轻微上浮 | 600ms | P0 |
| angry | 头顶一个 💢 符号 + 左右抖一下 | 450ms | P0 |
| wave | 手边 2 条弧线（挥手轨迹） | 400ms | P1 |
| stretch | 身体两侧 2 颗星星 + 向上淡出 | 500ms | P1 |
| sleep | 头顶 3 个 z 依次上浮 | 循环（睡觉期间） | P1 |
| drag | 身后 2 条速度线 | 拖拽期间 | P2 |
| idle | 偶尔眨眼 / 一颗小星 | 随机 8–15s | P3 |

### 4. 与现有代码的接入点

- 特效由 `main.ts` 的 `onStateChange` 统一触发（和气泡、音效同一处）
- 不需要改 `PetView`；`petpet.ts` 的手掌是独立层，特效层放在它下面
- 新增 `src/renderer/fx.ts`：`playFx(name)` + 自动清理
- 资源放 `src/renderer/assets/fx/`，单张 ≤10KB

### 5. 验收

- 连续快速点击 20 次不残留 DOM、不叠层
- 空闲 CPU 不超过 6%
- 关闭「动画速度」到 0.5× 时特效明显变慢
- 勿扰模式下特效仍然播放（纯视觉，不打扰）

## 二、音效发展

### 1. 现状

- `src/renderer/audio.ts` 用 Web Audio 合成正弦/方波
- 三套性格只有基频差异，听感接近
- `PetPack.sounds` 字段已预留，但没有真实素材

### 2. 目标（C2）

每个性格 5 类音效，**≤3 秒**，可商用授权：

| 类别 | 触发 | 建议 |
|---|---|---|
| click | 单击 | 轻“啵”/短铃 |
| drag | 拖拽开始 | 布偶摩擦/轻呼 |
| sleep | 进入睡眠 | 轻柔下行音 |
| appear | 启动/切回 | 短问候音 |
| confirm | 设置保存/导入成功 | 明亮确认音 |

### 3. 分阶段

| 阶段 | 内容 | 产出 |
|---|---|---|
| A | 保留合成音作为兜底 | 已有 |
| B | 接入 5 类真实音效 × 3 套 | `resources/sounds/{id}/*.ogg` + `pack.sounds` |
| C | 同动作 2–3 个变体随机，避免重复 | 变体表 |
| D | 音量归一化 + 限幅，避免爆音 | -16 LUFS，峰值 ≤ -1dB |
| E | 性格化混音（害羞更轻、开朗更亮、傲娇更短） | 混音参数 |

### 4. 技术接入

- `PetPack.sounds` 已存在：`Partial<Record<AnimationName, string>>`
- 用 `AudioContext.decodeAudioData` 预加载，首次播放无延迟
- 同一音效同时最多 2 个实例；静音/勿扰直接不播
- 文件格式优先 `.ogg`（体积小），兼容性兜底 `.wav`
- 播放失败静默回退到合成音，不能报错

### 5. 授权

- 只用 **CC0 / 明确可商用** 素材：Freesound（CC0 筛选）、Pixabay、ZapSplat（需署名）
- 每个文件在 `resources/sounds/LICENSE.md` 记录来源、作者、许可证、下载日期
- 拿不准的素材不用；能自己录的优先自己录

### 6. 验收

- 遮住名字随机播放，能听出三套性格差异
- 连续点击 10 次无爆音、无叠加失真
- 静音/勿扰下完全无声
- 增加音效后空闲 CPU 涨幅 <1%

---

## 三、建议排期

1. **P0**：click / pat / angry 三个特效 + 5 类音效素材收集
2. **P1**：wave / stretch / sleep 特效 + 三套音效接入
3. **P2**：drag / idle 特效 + 变体随机 + 混音
