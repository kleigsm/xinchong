# 2026-11-05 · P1-4 台词气泡

## 目标

让它"说话"：点击 / 拖拽时冒一句台词，几秒后自动消失。

## 完成内容

### 1. 窗口布局改造

原来窗口 220×220、角色居中，装不下头顶的气泡。

改为 **320×340**：

```
┌──────────────┐
│   气泡区      │  ← 上方 180px 留给气泡
│              │
│  ┌────────┐  │
│  │  角色   │  │  ← 160×160，贴底居中
│  └────────┘  │
└──────────────┘
```

联动改动：
- `shared/constants.ts`：`WINDOW_WIDTH / WINDOW_HEIGHT / PET_SIZE`
- `main/window.ts`：窗口尺寸与默认位置
- `main/hit-test.ts`：命中圆心改为「窗口底部往上 PET_SIZE/2」

### 2. 气泡组件 `src/renderer/bubble.ts`

- `SpeechBubble.show(text, durationMs=3000)`：显示并自动淡出
- 再次 show 会替换文本并重置计时
- `LinePicker`：随机取台词，**避开最近 10 条**，防止连续重复

### 3. 接线

| 事件 | 行为 |
|---|---|
| 点击（状态进入 click） | 从 `lines.click` 取一句 |
| 拖拽开始 | 从 `lines.drag` 取一句 |
| 设置变化（静音/勿扰） | 用气泡反馈，替代原来的底部提示文字 |

顺手删掉了 `#hint` 元素——它的作用被气泡取代了。
