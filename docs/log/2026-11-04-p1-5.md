# 2026-11-04 · P1-5 托盘与右键菜单

## 目标

给桌宠一个常驻入口：托盘图标 + 右键菜单（显示/隐藏、设置占位、退出），解决"只能 Ctrl+C 关闭"的问题。

## 完成内容

- `src/main/tray.ts`：托盘创建、菜单构建、显示/隐藏切换、退出
- 图标内嵌为 32×32 PNG 的 base64，**不依赖资源路径**，开发与打包一致
- 托盘菜单与宠物右键菜单**共用同一份** `buildMenu()`
- 右键菜单经 IPC（`show-context-menu`）弹出，渲染层只负责触发
- 窗口被托盘隐藏时，`hit-test` 暂停检测（`win.isVisible()` 判断）

## 踩的坑

1. **PowerShell 写代码时模板字符串被吞**：`"${VAR}"` 在双引号 here-string 里会被展开成空。改用单引号 here-string + 占位符替换。
2. **右键触发了拖拽**：`mousedown` 没判断按键，右键也会走拖拽流程。加 `if (event.button !== 0) return;`。
3. **合成鼠标点击受 DPI 影响**：每个新的 PowerShell 进程默认不感知 DPI，`SetCursorPos` 会被缩放 1.25 倍导致点空。测 UI 前必须先 `SetProcessDPIAware()`。
