# 2026-11-06 · C3 引导文案（怎么玩）

## 问题

功能已经堆了不少：双击招手、长按摸头、连点生气、右键聊天……**但用户不知道**。

一个新用户打开只会点一下，然后觉得"哦，它说句话"。剩下 80% 的功能等于不存在。

## 完成内容

### 1. 首次启动说一句引导

第一次运行时，它会自己冒一句：

> 双击我、长按我都可以试试～右键还有更多

用气泡而不是弹窗——桌宠用弹窗介绍自己很出戏，而且会被立刻关掉。

实现上加了个 `hasSeenGuide` 设置项，**只说一次**。改设置回传时不会重复弹（有 `guideShown` 一次性标记）。

### 2. 设置里新增「怎么玩」页

分成四张卡：

| 卡片 | 内容 |
|---|---|
| 基本交互 | 单击 / 双击 / 长按 1.2s / 连点三下 / 拖动 |
| 自己待着的时候 | 一直不动会睡、睡着点一下会伸懒腰、深夜有特别台词 |
| 右键菜单 | 说句话 / 我的角色 / 性格 / 动作 / 设置 |
| 换个样子 | 导入立绘、导入雪碧图、下载模板 |
| 觉得它太闹？ | 静音 / 勿扰 / 不睡 / 关手势 |

写成了「操作 → 效果」的对照表，扫一眼就能看完。

### 3. 隐私说明集中到两处

- 「聊天」页：Key 存哪、怎么加密、什么时候会联网
- 「关于」页：所有数据都在本机
