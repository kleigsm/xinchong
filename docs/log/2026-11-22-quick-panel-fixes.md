# 2026-11-22 · 快捷面板 v1.1（补「说句话」+ 不再遮挡桌宠）

## 两个问题（用户实测反馈）

1. **没有「说句话」**：第一版只有 4 个动作，聊天入口漏了——而聊天恰恰是最高频的。
2. **会遮挡桌宠**：面板按"光标右上方"定位，右键时鼠标就在桌宠身上，结果面板压住宠物。

## 改法

### 1. 补「说句话」（整行按钮）

- 面板头部下方加一个整行按钮 `💬 说句话…`
- 点击 → 先关面板，再调已有的 `openChatInput(win)`（复用聊天输入条的焦点逻辑）
- 顺序很重要：面板失焦时会把焦点抢回去，所以必须**先关面板再开输入条**

### 2. 定位改成「以桌宠为参照」

原来是光标相对定位，现在是桌宠相对定位，按优先级找第一个"完整在屏内 + 不和桌宠相交"的位置：

```
① 桌宠上方  ② 桌宠左侧  ③ 桌宠右侧  ④ 桌宠下方
```

- 每个候选都会夹进当前显示器工作区
- 全部都不行（桌宠几乎占满屏幕）→ 退到"离桌宠远的那一侧"，仍然夹进工作区
- 计算用 DIP 坐标（`getBounds` / `workArea`），不做缩放换算

实测：默认位置（桌宠在右下角）时，面板出现在**桌宠左侧**（`(768,396)`），和桌宠边界留 8px 间隙。

## v1.2（同日，按用户反馈再修两处）

### 1. 面板离桌宠太远

上一版按**窗口**（320×340）算间距，但角色只有 160×160、居中贴底，
等于左右各多空出 80px，视觉上"离得很远"。

改成按**角色本体**（`win.x + (w-160)/2`，贴底 160 高）算，间距 8px：

| | 旧 | 新 |
|---|---|---|
| 参照 | 窗口 320×340 | 角色 160×160 |
| 默认落点 | 桌宠左侧 `(768,396)` | 角色上方 `(1096,170)`，间距 8px |

### 2. 面板不跟随桌宠

面板是独立窗口，桌宠被拖走时它原地不动。现在：

- 监听桌宠窗口 `move`，面板按**相同位移**同步移动（保持相对位置，不重新选边）
- 拖拽期间**不因失焦关闭**（`isDragging()` 时跳过关闭），否则一抓桌宠面板就没了
- 拖完停稳 400ms 后把焦点收回面板，恢复 Esc / 点外部关闭

实测：面板 `(1096,170)` → 拖动桌宠 `(1096,416)→(919,323)` → 面板跟着移到 `(919,77)`，全程保持打开。
