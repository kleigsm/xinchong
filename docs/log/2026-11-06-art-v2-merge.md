## 我做的三件事

### 1. 处理落后与冲突

他的分支落后 main 5 个提交（缺设置面板、素材模板、Key 存储、话术引擎接入）。
合并后只有 `src/shared/pet-pack.ts` 一处文本冲突——因为我和林予炫刚把 `LineBank` 挪到 `lines.ts`。

解决方式：保留 `LineBank` 的再导出，同时采用他的 8 个 `AnimationName`。

### 2. 修「长按吃掉拖拽」

原实现：

```ts
// 长按 650ms 触发摸头后
if (patTriggered) return;   // ← 之后移动鼠标不再开始拖拽
```

用户按住想拖、手停 0.65 秒 → 变成摸头，然后**拖不动了**。

改成：

- 长按阈值 **650ms → 1200ms**（避开拖拽的犹豫期）
- 移除那个早退，允许摸头后继续拖（摸头动画被拖拽打断，符合直觉）

### 3. 修文档不一致

`actions-v2.md` 原写「导入器暂不支持 4×9」，但代码已支持 9 行，改成如实描述。

## 关于 `art/` 目录

他的 PR 里带了 2876 行 Python：矢量生成器 + skill（`art/gen.py`、`art/skill/`、`art/template/`）。

**决定入库**：素材是**代码生成**的，意味着以后改配色、加动作可以重新生成，是可复现的技术资产。
它不进构建产物（`files` 只含 `out/` 和 `package.json`），对安装包无影响。

## 遗留

- 四个新动作**没有台词和音效**（走的是对应的基础音效或没有）
- 手势可发现性差：用户不知道能双击/长按，需要引导文案（C3）
- 长按 1.2 秒仍可能与"按住想拖但手抖"冲突，后续可考虑只保留右键菜单触发
