## 抓到的三个坑

### ① EPIPE：打包后一写日志就崩（最严重）

双击后弹「JavaScript error occurred in the main process」，
堆栈是 `Error: EPIPE: broken pipe, write` at `console.log`。

**原因**：GUI 应用没有控制台，stdout 是断开的管道；而渲染层 console 会转发到主进程，
一启动就写 → 抛错。

**修复**：`setupLogging()` 在打包模式下把日志写进 `%APPDATA%\xinchong\main.log`。

> 这个坑只在打包后出现，dev 永远看不到——**这就是提前打包验证的价值**。

### ② `ELECTRON_RUN_AS_NODE=1` 导致静默退出

exe 一闪而过、无窗口、无报错。原因是环境变量让 Electron 以 Node 模式跑。

排查了一轮才发现——**和我自己终端里的环境变量有关**，用户双击不会遇到。
但值得记下来，以后测试时先清掉。

### ③ PowerShell 写坏了 package.json

用 `ConvertTo-Json | Out-File` 回写，中文变乱码且吞掉引号，
electron-builder 报 `JSON.parse` 失败。

**规矩**：package.json 一律用编辑器改。
