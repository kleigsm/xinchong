# 2026-11-05 · P1-2 交互状态机

## 目标

让桌宠有"自动行为"：不用人操作也会动、会睡、被点会醒。

## 完成内容

`src/renderer/state-machine.ts`

```
   ┌──────── 点击 ────────┐
   ▼                      │
 click ──(播完)──> idle ───┘
                    │
                    │ 30 秒无互动
                    ▼
                  sleep ──(点击)──> click
```

- 四态：`idle` / `click` / `drag` / `sleep`
- `start()` 强制进入待机（**修了一个 bug，见下**）
- 点击：播非循环反应动画，播完自动回待机；连点会重播
- 拖拽：优先级最高，进入 `drag` 后不响应点击动画
- 睡眠：待机 30 秒自动进入；点击唤醒
- 状态变化通过 `onStateChange` 回调暴露，供 P1-4 气泡订阅

## 修的两个问题

### 1. `start()` 空转（严重）

初始 `state` 就是 `"idle"`，`start()` 调 `enter("idle")` 被"同状态不重复进入"的判断挡掉，
**结果待机动画和睡眠计时器都没启动**——表现是"放着不管永远不会睡，甚至不动"。

修法：`state` 初始为 `null`，`start()` 用 `enter("idle", true)` 强制进入。

### 2. Chromium 后台节流

`focusable: false` 的窗口可能被判定为不活跃，定时器被降频，导致"30 秒入睡"失准。
在窗口上关掉 `backgroundThrottling`。

## 验证结果

（临时把阈值调成 8 秒以便快速验证，验证后已改回 30 秒）

| 场景 | 日志 | 结果 |
|---|---|---|
| 启动 | `t=250ms init → idle` | ✅ 待机动画启动 |
| 8 秒无互动 | `t=8265ms idle → sleep` | ✅ 准时入睡 |
| 睡眠中点击 | `sleep → click → idle` | ✅ 唤醒并播反应 |
| 连点 10 次 | `click → click` 循环，无崩溃 | ✅ |
| 睡眠中拖拽 | `sleep → drag → idle` | ✅ |
| 点击动画被打断 | 拖拽优先，不播点击 | ✅ |
