# 2026-11-05 · 接入美术第一版（害羞套）

## 素材

美术交付的 512×512 PNG，4 列 × 4 行、每格 128、透明背景。

## 逐格校验结果

用脚本采样每格的不透明像素占比：

| 格子 | 占比 | 判定 |
|---|---|---|
| 0–3（待机） | 39.6–39.9% | ✅ 有内容 |
| 4–7（点击） | 36.1–39.8% | ✅ 有内容 |
| 8–9（拖拽） | 39.6–40.1% | ✅ 有内容 |
| 10、11 | 0% | ✅ 空（正确） |
| 12–13（睡觉） | 39.5–39.9% | ✅ 有内容 |
| 14、15 | 0% | ✅ 空（正确） |

**16 格全部符合规格。** 内容格占比高度一致（都在 ~39%），说明角色大小统一、居中良好。

## 接入方式

**零代码改动**——帧号本来就是这样配的：

```ts
idle:  [0,1,2,3]
click: [4,5,6,7]
drag:  [8,9]
sleep: [12,13]
```

只把 `pet-shy.png` 覆盖掉旧的占位图，重新构建即可。
