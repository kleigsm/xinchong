# 2026-11-05 · P1-1 渲染层（播放器 + 占位素材）

## 目标

把"静态粉色圆"换成"会动的角色"，为状态机（P1-2）打好底座。

## 完成内容

### 1. 角色包格式 `src/shared/pet-pack.ts`

B 线的数据契约，美术交付 / 用户素材 / 程序播放都以它为准：

```ts
PetPack {
  sprite: { image, frameWidth, frameHeight, columns, rows }
  animations: { idle|click|drag|sleep: { frames[], fps, loop } }
  lines: { click[], drag[], idleLong[], sleep[] }
  sounds?: { ... }
}
```

**关键决策：雪碧图（sprite sheet）**，不是一堆独立 PNG。
理由：一次加载、切帧零延迟、不闪烁。

### 2. 占位角色（程序生成）

`scripts/gen-placeholder-sheet.ps1` → `src/renderer/assets/placeholder-sheet.png`

- 512×512，4×4 格，每格 128×128
- 行 0：待机（4 帧，末帧眨眼）
- 行 1：点击（4 帧，压扁弹起 + 开心眼 + 张嘴）
- 行 2：拖拽（2 帧，左右倾斜）
- 行 3：睡觉（2 帧，闭眼）

**美术素材到位后只需换图片 + 改几个参数，代码不用动。**

### 3. 播放器 `src/renderer/pet-view.ts`

- `play(name, onFinish?)` / `stop()` / `setPack()` / `play` 循环与非循环
- 用 `background-position` 百分比定位帧，`background-size` 按列行数缩放
- 非循环动画播完触发回调（点击反应 → 回待机就靠它）

### 4. 点击与拖拽的区分

新增 `DRAG_THRESHOLD = 4px`：位移小于 4px 算点击，大于算拖拽。
点击播 `click` 动画并回调回 `idle`；拖拽期间播 `drag` 循环。

## 踩的坑

**`declare module "*.png"` 放在有 import 的文件里会失效**——它会变成模块扩展而非环境声明。
必须单独建一个没有顶层 import/export 的 `assets.d.ts`。
