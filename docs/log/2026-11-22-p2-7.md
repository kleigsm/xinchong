# 2026-11-22 · P2-7 话术逻辑增强

## 目标

P2-5 的话术引擎上线两周，暴露出四个缺口（任务书 `docs/tasks/p2-7-dialogue.md`）：

1. `morning` / `idleLong` 定义了但没接入
2. 只在单场景内去重 → 点一下和拖一下可能挑到同一句
3. 聊天全靠 API → 说「晚安」也要花一次调用
4. 回复长度没约束 → `max_tokens: 80`，中文能到 40+ 字，气泡放不下

所以 7a 实际只剩 **`idleLong`**，没有重复实现。

## 完成内容

### 7b · 跨场景全局冷却（`src/renderer/line-engine.ts`）

- 新增 `cooldownMs` 选项和 `setCooldownMs()`（设置改了立刻生效）
- 内部维护 `lastSeenAt: Map<台词, 时间戳>`，**跨场景共用**
- `pick()`：先按本场景历史过滤，再按冷却过滤
- **冷却把库锁死时放宽冷却**：库只有一句时宁可重复，也不能哑掉
- `setBank()` 同时清空历史和冷却（换角色不串味）
- 单测 +5：跨场景不重复 / 过期可复用 / 库锁死仍说话 / 关闭冷却回到老行为 / `setCooldownMs`

### 7c · 本地意图识别（`src/renderer/intent.ts` + 单测）

- 6 个意图：`tired / insult / praise / goodnight / farewell / greeting`
- **规则顺序 = 优先级**，越具体越靠前：
  「你好烦」算骂它（不是问候）、「困了要睡」算说累（不是晚安）
- `INTENT_SCENE` 映射到本地场景：打招呼→`click`、告别→`wave`、晚安→`sleep`、夸它→`pat`、骂它→`angry`；
  说累没有对应场景，用固定安慰句 `COMFORT_LINES`
- `sendChat()` 里先 `detectIntent`，命中就**不调 API**，直接冒本地台词
- 13 条单测，重点测「不认错」

### 7d · 回复长度器（`src/shared/chat-text.ts` + 单测）

- 新增 `clipReply(text, max = 20)`：
  压成一行 → 不超长原样返回 → 超长切在**最近的标点后面**（保留标点）→ 没有合适标点就硬切 + 省略号
- 替换 `main/chat.ts` 里的 `slice(0, 60)`（会切在半个词上）
- 之所以单独一个文件：`main/chat.ts` 依赖 electron，测不了；纯函数抽出来才能单测
- 8 条单测

### 7a · `idleLong` 主动说话（`main.ts` + 设置页）

- 设置新增：`proactiveTalk`（默认 **false**）、`sceneCooldownMin`（默认 5，0 = 关闭）
- 行为页新增「说话」卡片：主动说话开关 + 台词冷却分段（关闭 / 3 / 5 / 10 分钟）
- 30 秒检查一次（只比两个时间戳，不新增高频定时器）；满足条件才说：
  `proactiveTalk` 开 → 不是勿扰 → `machine.current === "idle"`（没睡着 / 没在播动作）
  → 距上次交互 ≥ 5 分钟 → 距上次主动说话 ≥ 5 分钟
- 任何真实交互（点击 / 拖拽 / 打开输入条 / 菜单动作 / 发消息）都会 `markInteraction()` 重置计时
- 窗口隐藏时停掉定时器，不在后台空转

## 踩的坑

1. **冷却测试的前提写错了**：`idleLong` 池非空时引擎不会回退到 `click`（按场景取），
   所以「回退 + 冷却」要拿**空池**测，测试库改成了 `idleLong: []`。
2. **「你好烦」一开始被判成问候**：骂它词表里只有「烦死 / 烦人」，没有单字「烦」。
   补了单字并把「顺序即优先级」写进注释和测试（这正是 7c 最容易出的错）。
3. **长度器放进 `main/chat.ts` 就没法测**（依赖 electron），所以抽到 `shared/chat-text.ts`。

## 遗留

- `idleLong` 的「多久算久」固定 5 分钟（任务书只要求一个开关），没做成可配置。
- **睡着时不会主动说话**：默认 30 秒就睡了，所以要把它听到，得把「多久没互动就睡觉」调长或设「不睡」。
  行为页 hint 里写了这句。
- 意图规则以中文常见说法为主，英文只覆盖 `bye / hello / hi`；漏判只会多花一次 API，不会答错。
