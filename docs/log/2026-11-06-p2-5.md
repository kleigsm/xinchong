# 2026-11-06 · P2-5 话术引擎

## 目标

把现在「随机挑一句、不重复」的 `LinePicker`，升级成**按 性格 × 场景 挑台词**的引擎，
并且逻辑可单测（不依赖 window / DOM / 全局时间）。

## 完成内容

### 1. 台词库类型 `src/shared/lines.ts`（新建）

- `Scene`：6 个场景 `click / drag / idleLong / sleep / morning / night`
- `LineBank`：`click / drag / idleLong` 必填，`sleep / morning / night` 可选——
  **向后兼容**旧的 4 场景库（`default-lines.ts`、`pets/index.ts` 都不用改）

### 2. 引擎 `src/renderer/line-engine.ts`（新建）

`LineEngine`：`pick(scene)` / `setBank(bank)` / `hasScene(scene)`，构造参数注入 `random` / `now`。

6 条规则全部落地：

| # | 规则 | 实现 |
|---|---|---|
| 1 | 同场景不重复 | 有效历史长度 = `min(historySize, 库长-1)` 的滑动窗口 |
| 2 | 库不够降级 | 窗口自动收缩，3 条即退化成轮换，不报错 |
| 3 | 空场景回退 | 空 → 回退 `click` → 再空返回 `null` |
| 4 | 时间门禁 | `night` 只在 22:00–05:00 返回，其余 `null` 且**不回退** |
| 5 | 纯函数可测 | 只注入 `random` / `now`，不碰 window/DOM/全局时间 |
| 6 | 换库清历史 | `setBank()` 里 `recent.clear()` |

### 3. 单测 `src/renderer/line-engine.test.ts`（新建）

`vitest`，10 条用例全过（含任务书 5.2 的 6 条 + 规则 2/6、`hasScene`、缺失场景回退的补充）。

### 4. 其它改动

- `src/shared/pet-pack.ts`：`LineBank` 迁移到 `./lines`，保留再导出（兼容 `default-lines.ts` 的旧导入）
- `package.json`：加 `vitest`（devDep）和 `test` 脚本

## 踩的坑（本机环境）
