# 2026-11-05 · P2-1 后半 + P2-3 起步：我的角色

## 目标

导入的角色不能"用一次就没了"——要有列表、要记住、要能删。

## 完成内容

### 1. 持久化「当前用哪只」

`settings.json` 新增 `activePetId`：

```json
{ "activePetId": "art-shy-original" }
```

- 导入成功后自动写入
- 启动时读取，找到角色就换上，找不到就回退内置角色并清空字段

### 2. 托盘「我的角色」子菜单

```
我的角色 ▸
  ● art-shy-original     ← 当前使用中
    导入角色…
    删除当前角色
```

- 导入的角色按 id 列出，点一下立刻切换
- 删除当前角色会退回内置性格角色

### 3. 换回内置角色的通道

新增 `pet:builtin` 事件：主进程通知渲染层"别用用户角色了，换回内置的"。

渲染层的 `switchPersonality` 增加一个判断：

```ts
// 正在用用户角色时，即使目标内置角色和上次相同也要真的换回来
if (nextId === currentPackId && !usingUserPet) return;
```

不加这个判断的话，从用户角色切回「害羞」会被"同一个 id"挡住，什么都不会发生。

### 4. 收口逻辑 `src/main/pet-switch.ts`

`useStoredPet` / `useBuiltInPet` / `deleteStoredPet` 三个函数，
托盘、导入、启动恢复三处共用，避免各写一遍。
