# 2026-11-04 · 配置存储层 + P1-7 开机自启 + P1-6 状态

## 目标

先把「设置」这件事从零建起来：没有持久化，任何开关都是重启即失忆。

## 完成内容

### 1. 配置存储层（新增）

`src/main/store.ts`：一个 JSON 文件放在 `app.getPath("userData")/settings.json`。

```json
{ "muted": false, "dnd": false, "autoStart": false }
```

- 首次读取：文件不存在则用默认值
- 更新：合并 → 写盘 → 更新内存缓存
- **没有引入 electron-store**：最新版是纯 ESM，主进程打包容易踩模块格式的坑；需求只是读写一个小对象

### 2. P1-7 开机自启

`src/main/autostart.ts`

- 用 `app.setLoginItemSettings()` 写 `HKCU\...\Run`
- **默认关闭**（默认值 false）
- 启动时把配置同步到注册表，避免用户在系统设置里改过后状态不一致
- **开发模式不写注册表**：`process.execPath` 是 `electron.exe`，写进去会导致开机启动一个空的 Electron

### 3. P1-6 静音 / 勿扰（状态层）

- 托盘菜单新增三个复选框：静音、勿扰模式、开机自启
- 勾选后写盘，并通过 `settings-changed` IPC 推给渲染层
- 渲染层据此更新提示文字：`已静音` / `勿扰中` / 默认
- **音效与气泡尚未实现**（等 P1-1 / P1-2），所以目前只做到"状态与入口"
