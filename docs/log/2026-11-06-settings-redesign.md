# 2026-11-06 · 设置面板改版（卡片式）+ 行为分区

## 起因

参考了你给的 GameSir Nexus 界面，希望设置面板是那个风格；同时把"这些"（行为类配置）也放进设置里。

## 一、设计语言

从参考图拆出来的规则：

| 元素 | 做法 |
|---|---|
| 背景 | 浅灰 `#e9e9ec`（原来是暖白） |
| 卡片 | 纯白、16px 圆角、轻阴影，替代原来的描边卡片 |
| 强调色 | 暖橙红 `#f0603c`（呼应桌宠的橙红色天线/围巾） |
| 开关 | 胶囊 46×26，开是橙色、关是浅灰 |
| 分段选择器 | 灰底胶囊，选中项白底 + 橙字，替代一堆按钮 |
| 滑块 | 橙色填充 |
| 导航 | 去掉边框，选中项变成白色悬浮卡片 |

整体从"表单"变成"仪表盘"。

## 二、新增「行为」分区

| 设置项 | 控件 | 说明 |
|---|---|---|
| 多久没互动就睡觉 | 分段：30 秒 / 1 分钟 / 5 分钟 / **不睡** | 0 表示不自动睡 |
| 双击招手 | 开关 | 关掉后双击只当普通点击 |
| 长按摸头 | 开关 | 关掉后长按不再摸头 |
| 连点生气 | 开关 | 关掉后连点只是重复点击 |

对应字段：`idleToSleepMs` / `gestureWave` / `gesturePat` / `gestureAngry`。

## 三、实现要点

### 分段选择器是通用的

```ts
segmented(key, options, current)
```

以后加"动画速度""气泡时长"这类多选一，直接复用。

### 睡觉计时改成可动态调整

`PetStateMachine.setIdleTimeout(ms)`：

- 改完立刻按新值重新计时
- `0` 表示不睡：`scheduleSleep()` 里直接 return，不排定时器

### 手势开关

在三个手势的触发点各加一道判断，设置改动会通过 `settings-changed` 实时生效，不用重启。
