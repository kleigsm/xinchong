# 2026-11-05 · P1-3 性格系统

## 目标

三套性格可切换：**动作、台词、外观一起换**，像换了只宠物。

## 完成内容

### 1. 性格清单 `src/shared/personalities.ts`

```ts
PERSONALITIES = [
  { id: "shy",      label: "害羞" },
  { id: "cheerful", label: "开朗" },
  { id: "tsundere", label: "傲娇" },
]
```

主进程（托盘菜单）和渲染层（角色包映射）共用这一份，加新性格只改一处。

### 2. 三套角色包 `src/renderer/pets/index.ts`

| id | 颜色 | 台词风格 |
|---|---|---|
| shy | 粉 | 小声、害羞 |
| cheerful | 橙 | 热情、话多 |
| tsundere | 紫 | 嘴硬、傲娇 |

三套共用同一张雪碧图布局（4×4、128 格），只有图片和台词不同。

雪碧图由 `scripts/gen-placeholder-sheet.ps1` 生成，配色参数化。

### 3. 切换入口

托盘菜单 / 宠物右键菜单新增 **性格 ▸** 子菜单（radio 单选），选中后：

1. 写入 `settings.json` 的 `personality`
2. 通过 `settings-changed` 推给渲染层
3. 渲染层 `switchPersonality()`：换角色包 → 重建台词挑选器 → 回到待机 → 气泡提示「我是 XX 版哦」

## 踩的坑

1. **PowerShell 读无 BOM 的 UTF-8 脚本会把中文注释和下一行合并**，导致语法错误。
   解决：给 `.ps1` 写 UTF-8 BOM。
2. 切换时 `machine.start()` 会打出一条 `idle → idle` 的冗余日志（无害，待清理）。
