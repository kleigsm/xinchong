## 修了什么

### BUG-008 · 中文路径启动闪退且无提示

`src/main/index.ts` 在**应用就绪之前**检查程序所在路径（打包版看 `process.execPath`，开发版看 `app.getAppPath()`），
含非 ASCII 字符就 `dialog.showErrorBox` 说明原因并以 `app.exit(1)` 退出。

- 实测两种形态都过：
  ① 开发形态（`out/ + package.json`）放 `D:\中文路径测试` → 弹窗、**没有创建桌宠窗口**；
  ② **打包形态**（`win-unpacked`）放 `D:\中文路径测试2`，双击 `XinChong.exe` →
     `Error` 框写明「当前路径里含有中文或特殊字符：D:\中文路径测试2\XinChong.exe」
     （截图 `docs/design/shots/bug-008-path-dialog.png`）
- 这也是 D-404 那条「中文路径静默崩溃」在代码里的兜底

### BUG-015 · 音量显示 0% 但仍有声音

**根因不是「缺少字段」，而是 `volume: null`**：

- 设置页 `Math.round(null * 100)` → **0%**
- 音频侧 `settings.volume ?? 0.6` 把 `null` 当 nullish → **0.6 照常出声**

修复：`src/main/store.ts` 读盘时用 `readVolume()` 把 volume 收敛成 0–1 的数字，非法值回落 0.6。
实测：隔离 userData 写 `{"volume": null}` → 设置页显示 **60%**、音频按 60% 播放。

### BUG-023 · 关掉悬浮面板后隐私设置页还留着

三个窗口（桌宠 / 快捷面板 / 设置）各自独立，`win.hide()` 只作用于桌宠；
设置窗口的 `close` 又是 `preventDefault()` + `hide()`，于是「面板都关了，只剩一个设置页飘着」。

修复：`settings-window.ts` 新增 `hideSettingsWindow()`，在两条「收起」路径上调用：

- `tray.ts` →「显示 / 隐藏」的隐藏分支
- `quick-panel.ts` → 快捷面板「隐藏」

实测：面板点「隐藏」后设置页 `visibilityState` 从 `visible` 变 `hidden`。

### BUG-007 · 解压后不知道双击哪个

新增 `resources/先读我.txt`（启动步骤 / 怎么玩 / 怎么彻底退出 / 中文路径警告），
并通过 `electron-builder.yml` 的 `extraFiles` 放到解压根目录、与 `XinChong.exe` 同级。

实测：`pnpm build:win` 产出 138.7 MB zip，**根目录确实含 `先读我.txt`**。
是否真的减少困惑还要等 P3-3 用户测试。

## 踩的坑

1. **electron-builder 调 `pnpm list` 失败**：本机没有全局 pnpm（只有 `corepack pnpm`），
   electron-builder 内部直接 spawn `pnpm` → `CommandNotFoundException`。
   临时在 PATH 前面放了个 `pnpm.cmd` 转发到 `corepack pnpm` 才打出来（本机环境问题，没改仓库）。
2. **打包中途报 `unable to verify the first certificate`**：本机走代理（MITM 证书），
   Node 不信任。加 `NODE_OPTIONS=--use-system-ca` + `CSC_IDENTITY_AUTO_DISCOVERY=false` 后通过。
3. **BUG-015 的「缺少 volume 字段」猜想是错的**：缺字段会被默认值补上；
   真正触发的是 `null` —— `??` 和 `Math.round` 对 null 的处理不一致，才有了「0% 但有声」。
