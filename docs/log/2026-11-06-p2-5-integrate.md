## 接入改动 `src/renderer/main.ts`

| 原来 | 现在 |
|---|---|
| `clickLines = new LinePicker(...)` | `lineEngine = new LineEngine(pack.lines)` |
| `clickLines.next()` | `lineEngine.pick("click")` |
| `dragLines.next()` | `lineEngine.pick("drag")` |
| 换性格重建两个 picker | `lineEngine.setBank(pack.lines)` |
| 换用户角色重建两个 picker | `lineEngine.setBank(payload.pack.lines)` |

### 顺手用上了新场景

**① 深夜台词（30% 概率）**

```ts
const nightLine = Math.random() < 0.3 ? lineEngine.pick("night") : null;
const line = nightLine ?? lineEngine.pick("click");
```

白天 `pick("night")` 返回 null，自动跳过；深夜则有 30% 概率说"夜里的话"。
用概率而不是全部，是为了避免深夜点十下全是同一句。

**② 入睡台词（新场景 sleep）**

```ts
if (to === "sleep") {
  const line = lineEngine.pick("sleep");
  if (line) bubble.show(line, 4000);
}
```

现在它睡着之前会说一句"呼……呼……"，比无声无息地闭眼自然一些。

### 删掉死代码

`src/renderer/bubble.ts` 里的 `LinePicker` 类已无人使用（被 `LineEngine` 取代），删除。
