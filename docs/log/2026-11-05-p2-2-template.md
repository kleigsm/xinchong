# 2026-11-05 · P2-2 素材包模板

## 目标

用户想画自己的角色，光有 `asset-spec.md` 不够——需要**一个能直接打开照着改的包**。

## 完成内容

### 1. 模板目录 `resources/pet-pack-template/`

| 文件 | 内容 |
|---|---|
| `README.md` | 两种做法（只给一张图 / 画整套）、4 行与 5 行布局的格子图、四个动作要求、自查清单、常见错误 |
| `example-shy.png` | 官方「害羞」套的完整雪碧图，可以当参照直接照着画 |
| `pack-4row.json` | 4 行布局的配置示例 |
| `pack-5row.json` | 5 行布局的配置示例（推荐） |

README 特意写成"给画师看"的语气：短句、表格、ASCII 格子图，不讲代码。

### 2. 导出功能 `src/main/template.ts`

流程：**选保存位置 → 复制模板 → 用 PowerShell 压成 zip → 打开所在文件夹**。

为什么用 `Compress-Archive` 而不是加个 zip 库：
Windows 自带，零依赖，而且我们本来就是 Windows-only。

### 3. 打包配置

```yaml
extraResources:
  - from: resources/pet-pack-template
    to: template
```

模板必须**以真实文件存在**（`process.resourcesPath/template`），
不能塞进 asar——压缩工具访问不到 asar 里的虚拟路径。

### 4. 设置面板入口

角色页新增一行：

```
素材包模板    [下载模板…]
             含示例雪碧图、两种配置示例和绘制说明
```

## 验证

| 项 | 结果 |
|---|---|
| 保存对话框弹出 | ✅ 标题「保存素材包模板」，默认文件名正确 |
| 压缩产物 | ✅ 162.5 KB，含 4 个文件 |
| zip 内容完整性 | ✅ example-shy.png / pack-4row.json / pack-5row.json / README.md |

### 测试方式

用 `XINCHONG_EXPORT_TEMPLATE=1` 启动直接触发导出，再用 SendKeys 填路径。

**踩的坑**：系统保存对话框出现后，`SendKeys("{ENTER}")` 不生效——
需要先点一下对话框让它获得焦点。所以最终是用鼠标点「保存」验证的。

> 这也说明一件事：**桌宠窗口是 `focusable: false`，它弹出的对话框可能拿不到键盘焦点**。
> 真实用户点按钮时是用鼠标的，不受影响；但自动化测试要注意。

## 遗留

- 模板里没有"空白网格"底图（画师可以打开示例图新建图层代替）
- 模板没有版本号，`asset-spec.md` 升级时模板可能不同步
- 官网还没有这个模板的下载入口（等 P3-2）
