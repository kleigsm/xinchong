# 2026-11-05 · P1-10 性能基线

## 目标

把上面这套东西"量化"：数值可见、掉帧自动降、出一份基准报告。

## 完成内容

### 1. 性能数值可见

`src/main/perf.ts`

- `app.getAppMetrics()` 汇总所有进程的 CPU / 内存
- 托盘菜单新增「性能信息」，弹窗显示当前数值
- 设置 `XINCHONG_PERF=1` 时每 5 秒打一行日志

### 2. 卡顿自动降帧

`src/renderer/pet-view.ts`

- 每个 tick 记录实际间隔，超过预期 2.5 倍计为"慢帧"
- 连续 12 个慢帧 → 帧率降到 75%，最低 4fps
- 宁可慢，也不要堆积

### 3. 窗口隐藏时停止动画

`visibilitychange` → `view.stop()`；重新显示时恢复。
托盘隐藏后 CPU 归零。

### 4. 其它优化

- 光标轮询 50ms → 80ms
- 待机动画 8fps → 6fps

### 5. 基准报告

[`docs/perf-baseline.md`](../perf-baseline.md)：方法、结果、历史对比、剩余方向。

## 结果

**空闲 CPU 5.89% 单核，内存 442 MB**（30 秒采样，无交互）。

未达到「< 5%」的目标，差约 0.9pp。三个发现：

1. CPU 均匀摊在 renderer / gpu / main / audio 四处，没有单一元凶
2. 内存比 P0-2 多 70MB，主要来自音频服务常驻
3. 测量噪声约 ±0.5pp（多次测量 5.9%–6.9%）

## 判定

- **「不卡顿」红线：满足**（动画流畅、交互响应正常）
- **「低占用」期望：未达标**（5.89% vs 5%）

剩余优化方向已列在报告第六节（精灵条 + transform、空闲降频、音频按需创建）。
