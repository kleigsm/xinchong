按 BACKLOG，后面还有这么多东西要往这里塞：角色管理、话术库、音效包、聊天 Key、

```

│ 芯宠      │  角色                     │

```

**加功能 = 加一个左栏条目**，永远不乱。

## 技术要点

### 1. 多页构建

`electron.vite.config.ts` 的 renderer 加了第二个入口：

```ts
input: {
  index: resolve(__dirname, "src/renderer/index.html"),
  settings: resolve(__dirname, "src/renderer/settings/index.html"),
}
```

### 2. IPC 改用请求-响应

桌宠窗口用的是单向 `send`（够用），设置窗口需要**查**东西，所以新增 `invoke/handle`：

| 通道 | 用途 |
|---|---|
| `api:settings:get` / `patch` | 读写设置 |
| `api:pets:list` / `use` / `remove` / `rename` / `import` | 角色管理 |
| `api:system:info` | 版本、CPU、内存、数据目录 |
| `api:system:openUserData` / `openLogFolder` / `resetSettings` | 系统操作 |
| `api:system:confirm` | 二次确认对话框（主进程弹，更原生） |

`settings-changed` 广播保留，桌宠窗口能实时响应设置变化。

### 3. 缩略图

主进程用 `nativeImage.crop()` 裁出雪碧图第一格，`resize(72×72)` 后转 data URL。
渲染层拿不到文件系统，只能这样给。

### 4. 窗口行为

- 760 × 580，可缩放，有边框（和桌宠的透明窗完全独立）
- **关闭只是隐藏**，下次打开秒开
- 退出程序时强制销毁（`forceClose` 标记绕过拦截）

### 5. 即时生效，没有保存按钮

改音量立刻能听到，换性格立刻变——桌宠类产品不该有"保存"这一步。

### 6. 就地改名

点「改名」把名字变成输入框，Enter 提交、Esc 取消。
（Electron 不支持 `window.prompt`，所以只能自己实现。）

## 踩的坑

1. **按钮文字换行**：`.btn` 没设 `white-space: nowrap`，三个小按钮挤成两行。
2. **窗口"消失"**：其实是创建了但被其它窗口盖住，`Get-Process | MainWindowTitle` 看不到它。
   排查时用 `EnumWindows` 按标题枚举所有顶层窗口才找到。
3. **窗口被最小化后**，`GetWindowRect` 返回 `-25600,-25600`，截图全是空白。
