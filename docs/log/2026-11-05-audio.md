## 顺带修的一个 bug：BOM 导致设置被静默重置

**现象**：手动改过 `settings.json` 后，重启应用发现设置全没了。

**原因**：用 PowerShell / 记事本保存 JSON 会带 UTF-8 BOM，
`JSON.parse` 遇到 BOM 直接抛错，被 catch 吞掉后回退默认值——**没有任何提示**。

**修复**：读取时先 `replace(/^\uFEFF/, "")`。

这个 bug 很阴：数据其实没丢，但程序"看不见"，用户只会觉得"设置不保存"。
