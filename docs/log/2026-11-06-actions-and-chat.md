## A. 四个新动作的台词与音效

胡汇兴加了招手/伸懒腰/摸头/生气四个动作，但动作播了不说话也不出声，显得干。

### 台词

`Scene` 从 6 个扩到 10 个（新增 wave / stretch / pat / angry），三套角色各补了 3 句：

| 性格 | 招手 | 摸头 |
|---|---|---|
| 害羞 | 「……拜拜？」「你、你要走了吗」 | 「诶诶……」「别、别摸头啦」 |
| 开朗 | 「拜拜～」「下次再来玩！」 | 「嘿嘿～」「再摸一下！」 |
| 傲娇 | 「……走了别回来」「哼，慢走」 | 「谁、谁准你摸了」「……就这一次」 |

引擎挑不到就自动回退到 click 池，所以旧角色包不受影响。

### 音效

`SoundKind` 扩到 8 种，每个动作一个辨识度不同的合成音：

| 动作 | 音型 |
|---|---|
| 招手 | 轻快两连音（像"拜拜"） |
| 伸懒腰 | 缓缓上扬的滑音（像打哈欠） |
| 摸头 | 两声很轻的三角波"噗哟" |
| 生气 | 短促下滑的方波（像"哼"） |

`slide()` 增加了波形参数，生气用方波才有那种"哼"的刺感。

## B. 聊天调用（P2-6 主体）

### 入口

右键菜单 / 托盘新增 **「说句话…」**：

- 没配 Key → 弹窗提示去设置里填，不弹输入框
- 配了 Key → 桌宠头顶出现输入条

### 一个真问题：桌宠窗口打不了字

桌宠窗口为了「不抢焦点」被创建成 `focusable: false`，
结果**聊天框根本收不到键盘输入**。

修复：只在输入条打开期间临时 `setFocusable(true)` + `focus()`，
回车或 Esc 关闭后立刻恢复 `focusable: false`。

```
[chat] 打开输入条
[chat] 关闭输入条，恢复不可聚焦
```

这样既不影响"不打扰"的原则，又能正常打字。

### 调用

`src/main/chat.ts`：

```ts
sendChatMessage(text, personality)
```

- 读 Key → 拼 system prompt（按性格给语气）→ POST DeepSeek
- 强约束回复格式：一句话、≤20 字、不用句号、不说自己是 AI
- 超时 20 秒、只发用户这一句 + 性格设定，不发任何本地数据

### 失败回落（D-007 的硬要求）

| 情况 | 表现 |
|---|---|
| 没 Key | 弹窗提示，不进输入流程 |
| 401 / 429 / 超时 / 网络错误 | **用话术引擎挑一句内置台词**，绝不让它哑火 |
| 回复为空 | 同上 |
