## 二、修掉的三条

### BUG-010 输入条点别处不关闭（P1）

`closeChatInput()` 原来只有回车和 Esc 两个出口。补了两条：

1. **窗口失焦**：`openChatInput()` 里注册 `win.on("blur")`，触发时收起并 `send("pet:chat-close")` 让渲染层同步隐藏；
2. **点输入框外**：渲染层 `mousedown` 落在 `#chat-box` 之外（含点角色本体）立即收起。

实测：
- 点任务栏 → 日志 `[chat] 窗口失焦，自动收起输入条`，`chat-box.hidden = true`
- 点角色本体 → 日志 `[chat] 关闭输入条，恢复不可聚焦`

### BUG-011 拖到只剩一小截（P3）

`MIN_VISIBLE_PX = 60` 是按**窗口**算的，但角色贴窗口底部，窗口露 60px 时角色早没了。
改成按**角色中心**算（`PET_EDGE_MARGIN = 24`）：

```
petCenterX ∈ [area.x + 24, area.right - 24]
petCenterY ∈ [area.y + 24, area.bottom - 24]
```

实测拖到屏幕顶边，窗口停在 y ≈ -236（宠物中心距顶 24px，约 65% 身体可见）；
旧版日志里能到 y = -347，只剩一条边。

顺带说明：实际窗口高度是 348 而不是常量 340（Electron 的取整），
所以按 `bounds.height` 算出来的边界比手算的 -236 略深一点，这是对的——用的是真实 bounds。

### BUG-012 petpet 与 L2 抢 transform（P2）

两边都直接写 `petEl.style.transform`，逐帧互相覆盖。改成 **CSS 变量合成**：

```css
/* style.css */
#pet {
  transform: var(--petpet-transform,) var(--pet-anim-transform,);
}
```

- `PetView` 写 `--pet-anim-transform`（呼吸/点击/拖拽）
- `petpet` 写 `--petpet-transform`（按扁）

实测：两段同时设置，`getComputedStyle` 得到 `matrix(0.918, 0, 0, 0.8755, 10, 5)`
（1.02×0.9、1.03×0.85、位移 10,5 都在）。变量没设置时替换为空，等价 `transform: none`。

## 三、BUG-013 复现了，但这次没修

右键菜单弹出后，点窗口外的区域，菜单不关（开发版实测复现）。
原因：原生菜单靠鼠标捕获关闭，但我们的窗口「透明 + 部分穿透」，点在穿透区时事件直接去了别的窗口。

候选修法（写进 issue 了）：`popup` 期间临时 `setFocusable(true) + focus()`，`menu-will-close` 时恢复。
风险是可能破坏「置顶窗口不抢焦点」的设计（ARCHITECTURE 第八节），需要单独一轮验证，不塞进这批。
